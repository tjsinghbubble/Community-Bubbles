# mobile/.env — copy to mobile/.env and fill in. This file is committed; the real
# .env is gitignored. NEVER put a machine-specific name (a .local Bonjour name, a
# LAN IP, a personal Replit URL) in committed files — use the logical model below.
#
# See docs/dev-hosts.md for the full model and trade-offs.
#
# How EXPO_PUBLIC_API_URL should resolve, per target:
#   iOS simulator ............ http://localhost:3000        (native; no setup)
#   Android emu / Genymotion . http://localhost:3000        (run scripts/dev-connect.sh first)
#   USB real device .......... http://localhost:3000        (run scripts/dev-connect.sh first)
#   LAN peer machine ......... http://<that-machine-LAN-IP>:3000
#   Shared dev / staging ..... https://<your-dev-host>       (DNS + TLS; see docs §4)
#   Production ............... set in eas.json, not here     (https://trybubble.io)
#
# Default below assumes local dev with `scripts/dev-connect.sh <ios|android>` having
# set up the adb-reverse tunnels. EXPO_PUBLIC_* values are inlined into the JS bundle
# at build time, so restart Metro after changing this file.
EXPO_PUBLIC_API_URL=http://localhost:3000

# Google Places — required. Get a key in Google Cloud Console and restrict it by
# Android signing cert + iOS bundle id + the Places API. The app reads this exact
# (EXPO_PUBLIC_-prefixed) name; without it the app fails loudly at startup.
EXPO_PUBLIC_GOOGLE_PLACES_API_KEY=AIza


# CometChat — APP_ID is required; get it from https://www.cometchat.com/dashboard.
# (The App ID is a public client identifier, not a secret. There is intentionally
# no auth key here — the app does not use one client-side; production should mint
# auth tokens server-side via the CometChat REST key.)
EXPO_PUBLIC_COMETCHAT_APP_ID=167 
EXPO_PUBLIC_COMETCHAT_REGION=us

# name; scripts/dev-connect.sh maps it to a reachable address.
