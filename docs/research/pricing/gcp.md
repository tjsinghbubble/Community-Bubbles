## Example price points (us-central1, on-demand, monthly)

- **VM path (cheapest sane prod):** e2-standard-2 $48.92 + 30 GB pd-balanced boot $3.00 + external IPv4 $3.65 ≈ **$55.6/mo** (e2-medium variant: $24.46 + disk + IP ≈ **$31.1/mo**, but shared-core vCPUs).
- **Cloud Run path (min-instances=1, instance-based billing):** 2 vCPU / 4 GiB always-on ≈ **$152/mo** (1 vCPU / 2 GiB ≈ **$76/mo**) — includes HTTPS/LB/cert, no IPv4 or LB line items.
- **Cloud SQL PG16, smallest sensible prod:** db-custom-1-3840 (1 vCPU / 3.75 GB, Enterprise, zonal) + 20 GB SSD ≈ **$54/mo** (≈ $49.3 compute + $4.4 storage); with HA ≈ **$105–110/mo**.
- **GCS photos:** 50 GB Standard = $1.00 + 100 GB internet egress (Premium tier) = $12.00 → ≈ **$13/mo** (+ pennies for operations).

## Gotchas

- **e2 gets no sustained-use discount** — SUD only auto-applies to n1/n2/n2d/c2 families (up to ~20–30%). e2's list price is already the discount; use 1-yr committed use (~37% off) if the box is truly always-on.
- **External IPv4 is no longer free**: every in-use public IPv4 costs $0.005/hr (~$3.65/mo) since Feb 2024 — it shows up on VM, Cloud NAT, and LB line items.
- **Egress is the budget killer**: $0.12/GB from GCS/VM to the internet (Premium tier) is ~6x the cost of storing the same GB for a month. The 200 GB/mo free egress applies only to Standard network tier, not the default Premium tier.
- **Cloud Load Balancing has a ~$18/mo floor** (first-5-forwarding-rules charge) even at zero traffic — often more than the VM it fronts; a reverse proxy on the VM or Cloud Run's built-in HTTPS avoids it.
- **Cloud Run with min-instances=1 and CPU always allocated costs more than an equivalent e2 VM** (~$152 vs ~$49 for 2 vCPU/4 GiB) — you're paying for the serverless wrapper; the free tier (180k vCPU-s/mo) barely dents an always-on service.
- **Cloud SQL is priced per vCPU+RAM, not instance SKU**, and HA doubles compute and raises storage ~55%; backups (~$0.105/GB-mo) and storage auto-grow can quietly add 10–20% to the estimate. Third-party 2026 sources show SSD at $0.222/GB-mo (up from the older $0.17) — confirm in the calculator.
- **Free tier freebies worth taking**: 1 e2-micro (us-central1/east1/west1), 5 GB GCS regional, 30 GB pd-standard — useful for a bastion or staging, not for this prod box.
