## Example price points

- **App VM (2 vCPU / 4 GB, Cloud Compute High Performance NVMe):** **$24/mo** (100 GB NVMe + 5 TB transfer incl.); Regular Performance variant $20/mo.
- **Smallest Managed PostgreSQL:** **$18/mo** (1 vCPU / 1 GB / 32 GB on Cloud Compute HP, 0 replicas; marketing quotes $15/mo on Regular Performance). Production-ish 2 vCPU/4 GB/128 GB = $72/mo, +1 HA replica = $120/mo.
- **Object Storage base tier:** **$18/mo** Standard (1 TB storage + 1 TB transfer included).
- Realistic minimal stack: $24 VM + $18 managed PG + $18 object storage + $10 LB ≈ **$70/mo** (or ≈$60 without LB using Caddy on the VM).

## Gotchas

- **Included-transfer model, not per-GB egress:** every VM plan bundles 3–5 TB/mo of transfer, pooled account-wide and globally, plus 2 TB/mo free account-level egress; ingress is free. Overage is a flat $0.01/GB worldwide — vs ~$0.09/GB at AWS/GCP/Azure. For a <100 req/s API, egress cost is effectively $0.
- **Managed PG minimum is small but backup/PITR depends on plan tier:** the $15–18/mo entry plans (Hobbyist-class) have no point-in-time recovery; you need a Startup-class plan or better for PITR (2–30 day windows).
- **HA replicas are expensive relative to base:** each replica adds roughly 2/3 of the primary's cost (e.g., $72 → $120 → $168), and Optimized (dedicated vCPU) DB plans start at $90/mo — a big jump from shared-vCPU DB plans.
- **Object Storage minimum jumped:** the old $6/mo 250 GB plan is gone; the cheapest hot-storage entry is now $18/mo for the 1 TB Standard tier — you pay for 1 TB even if photos occupy 5 GB. (Archival tier is $6/TB but not suited to serving user photos.)
- **Stopped instances still bill** — Vultr charges while the instance exists, not while it runs; destroy to stop charges.
- **Third-party pricing summaries disagree on small items** (reserved IPv4 seen as $2 or $3/mo; DDoS as free or $10/mo). Official Vultr docs say Reserved IP = $3/mo and DDoS Protection add-on = $10/mo/instance; treat those as canonical.
