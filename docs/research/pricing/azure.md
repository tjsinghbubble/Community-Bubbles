## Example price points

- **B2s Linux VM (2 vCPU/4 GB), East US, PAYG:** $0.0416/hr × 730 h = **$30.37/mo** (+ OS disk, e.g. E4 32 GB Standard SSD $2.40/mo, + public IP $3.65/mo → ~$36.4/mo all-in).
- **PostgreSQL Flexible Server B1ms (1 vCore/2 GB) PG 16 + 32 GB storage:** $12.41 + $3.68 = **$16.09/mo** (backup within free allowance, no HA).
- **PostgreSQL Flexible Server B2s (2 vCore/4 GB) PG 16 + 32 GB storage:** $49.64 + $3.68 = **$53.32/mo**.
- **Blob Hot 50 GB (photos):** 50 × $0.0208 = **$1.04/mo** + a few cents of transactions.
- **100 GB/mo internet egress:** first 100 GB free → **$0/mo** (if total subscription egress ≤100 GB); if the allowance is already consumed, 100 GB × $0.087 ≈ **$8.70/mo**.
- **Container Apps always-on 2 vCPU/4 GiB, 1 min-replica:** ~**$152/mo** at active rate (schedulers keep it active); would be ~$46/mo if it idled at the reduced rate. Downsizing to 0.5 vCPU/1 GiB active ≈ $39/mo.

## Gotchas

- **B-series is burstable:** B2s banks CPU credits at 40% baseline (per-core baseline ~20%); a chatty scheduler or sustained load can exhaust credits and throttle. B2as v2/B2s v2 have higher baselines but ~2× the price.
- **Container Apps "idle" pricing rarely applies to this app:** the idle rate requires <0.01 vCPU and no requests; in-process schedulers keep replicas active, so a 2 vCPU/4 GiB min-replica app costs ~$152/mo — ~5× the equivalent B2s VM. Right-size the container (0.5 vCPU/1 GiB) or use the VM.
- **Flexible Server Burstable tier has no HA option**, and stopping the server only pauses compute for 7 days (then it auto-restarts and bills again). Storage can grow but never shrink.
- **Every public IPv4 now costs money** (~$3.65/mo Standard static); Basic SKU public IPs retire September 2025, so plan on Standard SKU pricing.
- **Egress free tier is per subscription, not per service** — the 100 GB/mo free allowance is shared across VM, Blob, and Container Apps traffic; LB data-processed ($0.005/GB) and NAT Gateway ($0.045/GB) charges stack ON TOP of bandwidth egress.
- **Managed disks bill by tier, not by used GB:** a 40 GB requirement rounds up to the 64 GB tier (E6). Standard SSD (not Premium) additionally charges $0.002/10k disk operations.
