## Example price points (us-east-1, on-demand, 730 hr/mo)

- **EC2 t4g.medium (2 vCPU / 4 GB, Linux)**: $0.0336 × 730 = **$24.53/mo**; + public IPv4 $3.65 + 30 GB gp3 $2.40 = **~$30.58/mo** all-in for the VM. (t3.medium x86 equivalent: **$30.37/mo** compute only.)
- **RDS db.t4g.small Single-AZ PG 16 + 20 GB gp3**: $23.36 instance + $2.30 storage = **~$25.66/mo** (backups within free allowance). Multi-AZ same config ≈ **~$51/mo**.
- **S3 50 GB Standard + 100 GB egress/mo**: storage $1.15 + egress $0 (covered by the 100 GB/mo free allowance if not consumed elsewhere; $9.00 if it is) + requests <$0.10 = **~$1.25–10.25/mo**.
- Reference stack total (t4g.medium + IPv4 + 30 GB gp3 + RDS small Single-AZ + S3, no ALB/NAT): **~$58/mo**; add ALB ≈ **~$75/mo**.

## Gotchas

- **Public IPv4 is no longer free**: $0.005/hr (~$3.65/mo) per address, charged even when idle. Budget one for the VM (and note an ALB uses one per AZ, min 2 AZs → ~$7.30/mo hidden in ALB cost).
- **100 GB/mo egress free allowance** is aggregated across ALL AWS services and regions per account — tiny-traffic photo serving may be effectively free, but it's shared, not per-service.
- **NAT gateway is a budget trap** (~$33/mo + $0.045/GB before any traffic). For one VM, use a public subnet with security groups instead of private-subnet+NAT.
- **Fargate ≈ 2.4× and App Runner ≈ 5× the cost of the equivalent t4g.medium** for an always-on 2 vCPU/4 GB container. Managed containers only pay off here for ops convenience, not price.
- **T-family "unlimited" bursting** is on by default: sustained CPU above baseline (20% per vCPU on t4g.medium) bills surplus credits at ~$0.04–0.05/vCPU-hr. Fine at <100 req/s, but worth monitoring.
- **Free tier changed in 2025+**: new accounts get up to $200 in credits for 6 months rather than the old 12-month always-free EC2/RDS hours; don't plan around perpetual free instances. No minimum commitments on anything above; 1-yr Savings Plans cut compute ~30–40% if the workload is confirmed stable.
