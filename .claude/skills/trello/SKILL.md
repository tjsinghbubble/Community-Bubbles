# Trello card filer

Files cards to the Bubble defects board (`https://trello.com/b/9sHE0OQV/bubbledefects`,
shortlink `9sHE0OQV`) using the Trello REST API via `curl`. Does **not** use `trello-cli` or the
CLI-Connector Power-Up (that Power-Up's hosted iframe is broken — SRI mismatch on
`power-up.min.js`). Pure REST is more reliable.

## Authentication (one-time setup)

Trello REST needs an **API key** + a **token**. The token is NOT the OAuth "Secret" — it must be
generated by authorizing the key:

1. Open (logged into Trello), click **Allow**, copy the token it shows:
   `https://trello.com/1/authorize?expiration=never&name=BubbleDefects%20Filer&scope=read,write&response_type=token&key=<API_KEY>`
2. Store creds where the script reads them — env vars, or appended to `~/.bubble_secrets`:
   ```sh
   export TRELLO_API_KEY=cbdbadc24645fb5b38e11c95b58913df
   export TRELLO_TOKEN=<the token from step 1>
   ```
   Keep the token out of git. It grants read/write to the user's boards.

Script is **zsh** (preferred over bash for these scripts). Invoke it as `zsh .../trello-card.zsh`
so it's covered by the existing `Bash(zsh *)` allow-rule (no per-command approval prompt).

## Batch workflow (preferred — review content, not every command)

Write one card per file under `tmp/trello-cards/*.md` (frontmatter + markdown body; see
`tmp/trello-cards/TEMPLATE.txt`), review/edit them, then file the whole directory in one shot:

```sh
zsh .claude/skills/trello/trello-card.zsh --dir tmp/trello-cards --dry-run   # offline preview
zsh .claude/skills/trello/trello-card.zsh --dir tmp/trello-cards             # file for real
```

Filed cards are moved to `tmp/trello-cards/filed/`. `--dry-run` parses + previews without creds or
network and does not move files. Frontmatter keys: `title, list, request_type, priority, platform,
menu_item, status, reviewed`.

## Single-card usage

```sh
zsh .claude/skills/trello/trello-card.zsh \
  --list "Feature/Functionality Defects" --title "..." --desc "$(cat body.md)" \
  --field "Request Type=Defect" --field "Priority=High" --field "Platform=All" \
  --field "Menu Item=Deployment, Monitoring, Logs" --field "Status=To do"
# or from a single file:  zsh .../trello-card.zsh --file tmp/trello-cards/foo.md
```

- `--list` accepts a list **name** (resolved on the board) or a raw 24-hex list id.
- `--desc` supports multi-line markdown (pass via `$(cat file)` or a quoted heredoc).
- `--field "Name=Value"` is repeatable; sets a **dropdown** custom field (name + option matched
  case-insensitively). Dropdown-only (the board's fields are all dropdowns).
- `--reviewed` suppresses the auto `(WIP)` prefix + "Unreviewed by Travis" footer.
- `--label` exists but the board's labels are color-only/unnamed; prefer the Priority field.
- Prints the created card's shortUrl on success.

Override the board with `TRELLO_BOARD=<shortlink|id>`; default list with `TRELLO_LIST=<name>`.

## Board schema (bubbledefects, 9sHE0OQV) — as of 2026-06-06

Lists: `UI Defects`, `UX Defects`, `Feature/Functionality Defects`, `In Progress`,
`Ready for Testing`, `Completed`.

Dropdown custom fields (set via `--field`):
- **Platform**: Mobile · Web · All
- **Priority**: Highest · High · Medium · Low · Lowest · Not sure
- **Request Type**: Feature · Defect
- **Menu Item**: Sign Up · Explore Page · Bubbles · Events · Messges/Chat · Notifications ·
  Profile · User Actions · Deployment, Monitoring, Logs
- **Status**: To do · In progress · Done · In review · Approved · Not sure

Re-dump anytime:
```sh
source ~/.bubble_secrets
curl -fsS "https://api.trello.com/1/boards/9sHE0OQV/customFields?key=$TRELLO_API_KEY&token=$TRELLO_TOKEN" \
  | node -e 'JSON.parse(require("fs").readFileSync(0)).forEach(f=>{console.log(f.name,"("+f.type+")");(f.options||[]).forEach(o=>console.log("  -",o.value&&o.value.text))})'
```

## Discovering lists / labels

```sh
curl -s "https://api.trello.com/1/boards/9sHE0OQV/lists?key=$TRELLO_API_KEY&token=$TRELLO_TOKEN" \
  | node -e 'JSON.parse(require("fs").readFileSync(0)).forEach(l=>console.log(l.id,l.name))'
```

## Verify auth

```sh
curl -s "https://api.trello.com/1/members/me?key=$TRELLO_API_KEY&token=$TRELLO_TOKEN" \
  | node -e 'const m=JSON.parse(require("fs").readFileSync(0)); console.log(m.username||m.message||m)'
```
A username = good. `invalid token` / `invalid key` = re-check the token (it is not the OAuth secret).

## Notes / caveats

- Creds are passed as curl args, so they're briefly visible to `ps` on this host — acceptable for a
  single-user local machine; do not run on shared hosts.
- The script never hardcodes secrets; it reads `TRELLO_API_KEY` / `TRELLO_TOKEN` from the
  environment, falling back to sourcing `~/.bubble_secrets`.
